## didademos

A collection of live demonstrations and functional code snippets created for my Blogger customization tutorials. This repository serves as a visual playground to showcase how specific features and layouts operate.

**Featured Demos:**
*   **Daily Release Schedule:** An automated layout for tracking recurring content updates.
*   **Anime List Style HTML Sitemap:** A clean, organized sitemap inspired by the Crunchyroll interface.
*   **3D Minimalist Bookshelf:** Featuring realistic book spines that open into a modern side-by-side modal view on mobile and desktop.

**Live Link:** [https://didanim.github.io/didademos/index.html](https://didanim.github.io/didademos/index.html)
