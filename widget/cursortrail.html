How to Add to Blogger

  1. 1
    Copy the Generated Code Click the "Copy HTML/JS" button above to save the widget snippet to your clipboard.
  2. 2
    Log into Blogger & Go to Layout Navigate to your Blogger Dashboard, select your blog, and click on Layout in the left sidebar menu.
  3. 3
    Add a HTML/JavaScript Gadget Click "+ Add a Gadget" in your Sidebar, Footer, or Cross-Column section. In the pop-up list, select HTML/JavaScript.
  4. 4
    Paste & Save Leave the Title field blank (or give it a name like "Cursor Trail"). Paste the copied code into the Content box and click Save.
